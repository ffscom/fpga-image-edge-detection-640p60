# 实时图像边缘检测与显示系统

基于易灵思Ti60F225 FPGA、SC431HAI摄像头与板载DDR3，实现图像采集、Canny边缘检测、灰度几何识别及HDMI交互显示。处理图像为640×480，HDMI按60Hz设计时序输出。

系统提供四种显示模式、按键调阈值、冻结恢复、16帧原始历史录制与回放、指定帧查看及两帧灰度比较；灰度支路在固定光照单纸样条件下识别圆、矩形和三角形，并叠加中文标签与目标框。实现、来源和验证范围见技术报告。
